# Hakim Skill

Hakim is an evidence-bound coding skill for AI-assisted development. It favors the smallest safe change, prefers reuse and native capabilities before new machinery, and keeps consequential claims tied to inspectable evidence.

The maintained skill package contains the canonical policy, specialized capability skills, installation/help documentation, required legal notices, and an optional deterministic complexity-audit helper. Repository test harnesses, release history, and validation evidence are not part of the installed skill package.

Hakim does not claim universal compatibility, model-quality improvement, performance gains, token savings, or complete security review.
