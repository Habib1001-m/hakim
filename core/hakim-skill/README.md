# Hakim Skill

Hakim is an evidence-bound coding judgment layer for AI-assisted development. It favors the smallest sufficient safe change, prefers reuse and native capabilities before new machinery, and keeps consequential claims tied to inspectable evidence.

The maintained package exposes exactly six semantic capabilities:

```text
hakim  review  audit  debt  status  help
```

`hakim` owns core execution judgment and `lite | full | ultra | off` mode control. The five specialized skills remain bounded to their explicit review, audit, debt, evidence-status, and help scopes.

The package contains the canonical skill contracts, capability mapping, installation/help documentation, required legal notices, and an optional deterministic complexity-audit helper. Repository test harnesses, release history, and validation evidence are not part of the installed skill package.

Hakim does not claim universal compatibility, model-quality improvement, performance gains, token savings, cost savings, complete security review, or ROI without separate evidence.
